# ClubOS Demo V1.0 — 可操作网页 Demo

面向户外俱乐部 / 亲子机构 / 活动组织者的 **AI 活动发布工具** 演示版。
一句话描述活动 → AI 自动识别信息、生成文案与排版 → 手机端实时预览 → 发布 → 前端报名。

> 不接真实支付、不接真实 AI 接口，全部为本地 Mock 数据，开箱即用。

## 运行方式

直接用浏览器打开 `index.html` 即可（无需构建）。
如需最佳效果（含在线字体），可在本目录启动静态服务：

```bash
python3 -m http.server 8123
# 浏览器访问 http://localhost:8123/
```

## 完整可操作闭环

1. 登录（任意手机号，验证码 `1234` 或留空均可进入）
2. 工作台输入一句话，或点示例 / 粘贴旧文案
3. 点击 **AI 生成活动** → 生成动画
4. 在编辑台确认 / 微调信息（左侧改、右侧手机实时预览）
5. 上传普通照片（自动裁切，无需调尺寸）
6. 用 AI 指令修改（如「把价格改成 269 元」）
7. 点击 **发布活动** → 跳转到手机端活动页
8. 前端点击 **立即报名** → 填写 → 提交
9. 显示 **报名成功**
10. 返回工作台 → 报名名单 查看记录

## 目录

- `index.html` — 入口
- `styles.css` — 设计系统（山野小队品牌：自然 / 温暖 / 专业 / 克制）
- `app.js` — 状态、Mock AI 解析、所有页面与交互

## 数据说明

所有活动与报名数据保存在浏览器 `localStorage`（key: `clubos_v1`）。
清除该 key 或换浏览器即可恢复初始示例数据。
